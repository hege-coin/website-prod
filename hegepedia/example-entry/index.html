A short and punchy intro text goes here. It should summarize the gist of the whole entry and make the reader curious to read on. On mobile, this text will be shown right above the infobox.

Lots of Lists

Lists are great. Here’s a bunch of different ones you can use.

First a regular unordered list:

  • Item One.
  • Item Two.
  • Item Three.
  • And finally a really really really long list item that for sure will wrap the line, because we need to make sure that works, too.

Then an ordered list:

  1. I’m in spot number 1!
  2. I follow on the second spot.
  3. I snagged the third place.
  4. And finally here I am, a lowly four, but a really really really long four because I need to make to sure wrap the line.

Then a definition list:

Term 1
Definition 1
Term 2
Definition 2
A second definition 2
Term 3
A really really really long definition that spans at least one line, maybe even more than that if this goes on.

And with that list, this list of lists is complete.

Links to Other Entries

You can (and should) of course link to other entries in the Hegepedia.

Use the shortcode hp/elink to do this.

If you call it with one argument, it will use the entry’s title for the link text, like this:

The Typewriter

If you call hp/elink with two arguments, it will use the second argument as the link text, like this:

A link to the Typewriter with a custom link text

As you see above, links within Hegepedia will automatically have a little magnifying glass added after them, to show that they lead to another Hegepdia entry.

To link to many entries at once, use the hp/elinks shortcode.

  • The Typewriter
  • Hege
  • Hegena

The hp/elinks shortcode can also list all entries with a given tag:

  • Hege
  • Hegena
  • Hendrix
  • Helena

Or a combination of tags (all tags need to match):

  • Hege

When you link to many entries at once like this, you can not set custom link texts.

Links to Other Entries With Thumbnails

Use the shortcode hp/ethumb to link to another entry showing its thumbnail instead of a text link. Pass in the id as the first argument, and optionally a custom caption as the second argument.

Use hp/ethumbs to link to multiple entries.

hp/ethumbs can also list all entries with a given tag:

Like with text links, when you link to many entries at once, you can not set custom captions.

Use the thumb_id parameter on any entry to set the gallery image to use as the thumbnail for that entry.

Gallery Items (Images and Videos)

Images and videos are stored as individual items in the gallery (technically each gallery item is a Hugo “Page”).

You can easily include them as figures in the entry using the g/fig shortcode.

Wrap figures in the g/list shortcode to display them as thumbnails, like below.

  • The first figure below is a single image.
  • The second has a custom caption.
  • The third shows how to disable the caption by setting it to the empty string.
  • The fourth is a video, which is inserted using the same shortcode as images.

If you click one of these figures, they will be shown in the media viewer. (Click the “i” icon inside the media viewer to go to the details page for that gallery item.)

Listing Multiple Images and Videos at Once
